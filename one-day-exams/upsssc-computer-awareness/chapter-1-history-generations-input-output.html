1. History & Pioneers of Computing

UPSSSC exam questions in this area test inventors, inventions, year of development, and key mechanical/electronic milestones.

Era / Machine Year Pioneer / Inventor Key Features & Significance
Abacus ~3000 BC Ancient Mesopotamia / China Earliest calculating device. Uses beads on parallel rods.
Napier’s Bones 1617 John Napier Used marked ivory rods for multiplication/division. Introduced Logarithms.
Pascaline 1642 Blaise Pascal First mechanical adding machine. Worked using gears, wheels, and dials.
Stepped Reckoner 1673 Gottfried Wilhelm Leibniz First mechanical calculator that performed all 4 basic operations (+, -, ×, ÷).
Jacquard Loom 1804 Joseph Marie Jacquard First machine to use punched cards to control woven pattern automation.
Difference Engine 1822 Charles Babbage Automatic mechanical calculator designed to calculate polynomial functions.
Analytical Engine 1837 Charles Babbage First general-purpose mechanical computer design. Included Input, Processing, Memory (Store), and Output. Charles Babbage is known as the "Father of Computers".
First Programmer 1843 Ada Lovelace Wrote the first algorithm (for Babbage’s Analytical Engine) to calculate Bernoulli numbers.
Tabulating Machine 1890 Herman Hollerith Electromechanical punched-card tabulator used for the 1890 US Census. Hollerith founded the company that became IBM in 1924.
Z1 / Z3 1936–1941 Konrad Zuse Z3 was the world's first working programmable, fully automatic digital computer.
ABC Computer 1942 John Atanasoff & Clifford Berry First electronic digital calculating device (Atanasoff-Berry Computer).
Mark I 1944 Howard Aiken First large-scale automatic electromechanical calculator built at Harvard with IBM.
ENIAC 1946 J. Presper Eckert & John Mauchly First general-purpose fully electronic digital computer. Used 18,000+ vacuum tubes.
EDSAC 1949 Maurice Wilkes First practical stored-program electronic computer.
EDVAC 1949 John von Neumann Introduced the Stored-Program Architecture (data and instructions reside in the same memory).
UNIVAC I 1951 Eckert & Mauchly First commercially produced electronic computer.

3. Hardware Architecture & System Bus

Computers follow the IPO Model (Input → Process → Output) based on the Von Neumann Architecture.

CPU Components

  • Control Unit (CU): Directs operations; fetches instructions, decodes them, and controls data flow. Known as the "Traffic Police" of the computer.
  • Arithmetic Logic Unit (ALU): Performs arithmetic (+, -, ×, ÷) and logical comparisons (>, <, =, AND, OR).
  • Registers: Tiny high-speed CPU memory.
    • PC (Program Counter): Holds address of the next instruction to execute.
    • IR (Instruction Register): Holds the current instruction being executed.
    • ACC (Accumulator): Holds immediate calculation results from ALU.

System Bus Components

  • Data Bus: Bidirectional — Carries data between CPU, memory, and devices.
  • Address Bus: Unidirectional — Carries physical memory addresses from CPU to RAM.
  • Control Bus: Bidirectional — Carries timing and control signals (Read/Write signals).

4. Computer Memory System & Hierarchy

Memory Hierarchy (Fastest & Most Expensive → Slowest & Cheapest):
Registers > Cache Memory (L1, L2, L3) > Primary RAM > Secondary Storage (SSD / Hard Disk)

A. Primary Memory (Volatile vs Non-Volatile)

  • RAM (Random Access Memory) - Volatile:
    • SRAM (Static RAM): Uses flip-flops; faster, no periodic refresh needed. Used in Cache memory.
    • DRAM (Dynamic RAM): Uses capacitors/transistors; requires constant electronic refreshing. Main system RAM.
  • ROM (Read-Only Memory) - Non-Volatile: Holds firmware like BIOS for the POST (Power-On Self-Test) routine.
    • PROM: Programmable once.
    • EPROM: Erased using Ultraviolet (UV) light.
    • EEPROM: Erased using Electrical signals (Pen drives and SSDs use flash EEPROM).

5. Input Devices

  • Keyboard: QWERTY layout (Invented by Christopher Latham Sholes).
    • Function Keys F1 (Help), F2 (Rename), F5 (Refresh/Slideshow), F12 (Save As).
    • Modifier Keys Ctrl, Alt, Shift.
    • Toggle Keys Caps Lock, Num Lock, Scroll Lock.
  • Pointing Devices: Mouse (Douglas Engelbart, 1964), Trackball, Joystick, Stylus/Light Pen, Digitizer.
  • Optical & Magnetic Readers:
    • OMR: Optical Mark Reader (Grades objective OMR answer sheets).
    • OCR: Optical Character Recognition (Converts scanned image text to editable text).
    • MICR: Magnetic Ink Character Recognition (Reads bank cheques; 9-digit MICR code: 3 City + 3 Bank + 3 Branch).
    • BCR & QR Reader: Reads 1D Barcodes and 2D QR matrix codes.

6. Output Devices

A. Monitors (Soft Copy Output)

Types: CRT, LCD, LED, OLED. Resolution is measured in total pixels, refresh rate in Hertz (Hz), and dot pitch measures pixel distance.

B. Printers & Plotters (Hard Copy Output)

Category Types Mechanism & Speed Metric
Impact Printers
(Physical contact)		 Dot Matrix, Daisy Wheel, Drum/Chain Printers Strikes inked ribbon onto paper. Loud and low quality. Speed measured in CPS (Characters Per Sec) or LPM (Lines Per Min).
Non-Impact Printers
(No contact)		 Inkjet, Laser, Thermal Printers Quiet & fast. Inkjet uses CMYK liquid ink. Laser uses Toner dry powder & laser beam. Speed in PPM (Pages Per Min).
Plotters Flatbed & Drum Plotters Prints large high-precision vector graphics, maps, and engineering blueprints using pens.

7. Software & Translators

  • System Software: Operating Systems, Language Translators, Device Drivers.
  • Application Software: MS Office, Web Browsers, Accounting software.
  • Utility Software: Maintenance tools (Antivirus, Disk Defragmenter, Backup utilities).
  • Language Translators:
    • Assembler: Assembly code → Machine code.
    • Compiler: Translates high-level source code to machine code all at once.
    • Interpreter: Translates high-level source code line-by-line during execution.
