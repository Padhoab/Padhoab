Standard Computer Syllabus

The UPSSSC Computer Awareness syllabus is broadly standardized around the following six areas.


1. Computer Fundamentals & Architecture

Generations, CPU, Input & Output Devices, Memory Hierarchy, Storage Devices and Computer Basics.

2. Networking & Internet

OSI Model, TCP/IP, IPv4 & IPv6, Web Browsers, Email, Internet Protocols and Networking Devices.

3. MS Office

MS Word, MS Excel, PowerPoint, Shortcuts, Functions and Productivity Tools.

4. Operating Systems & Hardware

Windows, Linux, Android, Mobile Computing, Printers and Hardware Components.

5. Digital Financial Tools & e-Governance

UPI, NEFT, RTGS, AEPS, DBT and important Government Digital Portals.

6. Emerging Technologies & Cyber Security

Artificial Intelligence, Machine Learning, IoT, Big Data, Cloud Computing, Malware and IT Act 2000.
