Chapter 4: Operating System

1. Operating System Concepts

  • OS Functions: Process Scheduling, Memory Allocation, File Management, Device Driver Management, Security & Authentication.
  • Types of Operating Systems:
    • Batch OS: Batches similar jobs sequentially (Early mainframes).
    • Time-Sharing OS: Uses CPU time slicing for multi-tasking (Unix, Windows).
    • Real-Time OS (RTOS): Guarantees output within rigid, deterministic time limits (Robotics, Flight controls).
    • CUI vs GUI: CUI relies on typed commands (MS-DOS, Unix); GUI relies on mouse, icons, and windows (Windows, Android).

2. Printers, Tablets & Mobile Technology

  • Spooling: Simultaneous Peripheral Operations On-Line — Temporarily queuing print jobs in RAM/Disk until printer is ready.
  • Capacitive vs Resistive Touchscreens: Capacitive uses electrical human touch (Modern Smartphones); Resistive requires physical pressure (ATMs).
  • Mobile SoC (System-on-a-Chip): Integrates CPU, GPU, Modem, and RAM onto a single chip (Snapdragon, Apple A-Series).
